Geometry as a sentence

The same forms can be sequenced as machine-readable civic instructions.

Use CIRCLE, SPIRAL, RADIAL, RINGS, and THRESHOLD separated by arrows, commas, or spaces.

Canonical examples

SPIRAL → CIRCLE → RADIAL
retrieve memory
→ bring into public witness
→ distribute through the network
RADIAL → RINGS → THRESHOLD
receive / distribute information
→ determine authorized access
→ permit or reject transition

Computational rule

EtherFlow = Geometry × Purpose × Access

This is a design rule, not a real-world physics equation. The executable implementation makes architecture behave like a system: rings become permissions, radial lines become networks, spirals become persistent memory, circles become shared state, and thresholds become transitions.

Cross-system role

The grammar is available to Luabi as machine-readable civic state, to Nago as a possible symbolic/tactile substrate, to architecture as spatial organization, to Ether infrastructure as routing logic, and to governance as witness/access/decision logic.

Reality boundary

UMADA Geometry Language is speculative worldbuilding and executable design fiction. The software can generate layouts and simulate civic rules; it is not evidence that real-world geometry manipulates an undiscovered Ether field.
