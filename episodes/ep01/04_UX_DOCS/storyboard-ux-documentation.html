UMADA · Cape Wipeout, Pt. 1

Storyboard as UX Documentation

Design document — not the primary story reader. The complete board explains fixed history, audience-choice hubs, investigative branches, convergence points, rescue perspectives, and closure.

Complete revised board

UX role legend

  • Fixed anchor
    Locked event; outcome cannot change.
  • Hub
    Opens route selection.
  • Branch
    Optional evidence or witness route.
  • Convergence
    Required history reached through different contexts.
  • Rescue hub
    Post-blast witness selection.
