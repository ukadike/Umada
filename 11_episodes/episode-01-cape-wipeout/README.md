**A Luabi Witness Record.**

overwritten — v1 is a preserved artifact, v2 is the current cinematic
rebuild.

```text
episode-01-cape-wipeout/
├── v1-archive/   the original public interactive prototype, unmodified
└── v2/           the current version — see v2/README.md
```

## Which one to open

- **Reading the episode:** open `v2/index.html`.
- **Comparing against the original public prototype:** open
  `v1-archive/03_PROTOTYPE/episode-cape-wipeout-pt1-interactive.html`.

## Why both exist

v2 rebuilds the audience-facing story around the newer UMADA canon (the
Council-Era prologue, the five ticks as five distinct scenes, the closing
wind-shift bridge to Cindy, and the Luabi/Omoluabi terminology split) while
reusing v1's proven interaction engine, evidence-channel model, witness
ledger, and accessibility foundation. See `v2/CHANGELOG.md` for the full
diff and `v2/README.md` for how to read it. v1 remains published, in place,
as the historical Draft 1 / Public Prototype v0.1 release.

The original publish location, `episodes/ep01/`, has also been left
untouched — this directory is an additional, versioned home for the
episode, not a replacement for that one.
