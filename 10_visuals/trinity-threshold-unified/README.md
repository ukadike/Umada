This directory contains the unified four-plate visual system for the UMADA Trinity Threshold hypothesis.

## Plates

1. **01-trinity-threshold.svg** — five-stage causal model: pre-existing Ether field → Trinity detonation → Threshold Pulse / Ether Shock → extraterrestrial recognition → alien conference.
2. **02-alien-detection-causal-chain.svg** — six-stage recognition and verification chain, including the timing argument.

4. **04-3i-atlas-control-sample.svg** — positions 3I/ATLAS as an independent interstellar comparison sample rather than a cause, redirect, proof, or locked alien spacecraft.

## Accessibility

Each plate is an SVG with a programmatic `<title>` and `<desc>`. The public Trinity Threshold page also provides image alt text and prose captions. The diagrams do not rely on color alone: sequence numbers, headings, arrows, labels, and textual boundary statements carry the same information as the green Ether-field accent.

## Real-world boundary

The plates intentionally separate established physics and history from UMADA speculative physics. Ordinary sound does not travel through interstellar vacuum; electromagnetic information is limited by light speed; Ether-field coupling, Threshold Pulse propagation, and extraterrestrial detection through that field are fictional worldbuilding mechanisms.
