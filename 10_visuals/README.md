# Visuals

This directory now holds the production-side visual development and interactive experience layer for UMADA. Canon-level visual registration remains governed by `01_canon/VISUAL_CANON_REGISTRY.md` and `data/visual_artifacts.json`; material here does not become visual canon merely by existing in this directory.

## Living landscape series

### 01 — Tisetan: Living Landscape

`10_visuals/tisetan-living-landscape-01/`

The first public proof-of-world surface: a p5.js civic-memory landscape with three canon-grounded encounters, a semantic ledger interface, keyboard/pointer controls, reduced-motion support, and a narrative gate into Cape Wipeout.

### 02 — Dead Glass: Transit Field

`10_visuals/dead-glass-transit-field-02/`

An abstract p5.js study of the existing Era 10 ledger entry: **network, infrastructure, information collapse**. Three inspectable states expose the same condition through different system lenses without introducing a new narrative event.

## Visual recovery

Earlier approved visual decisions whose binary source files are not yet present must be recorded as recovery gaps rather than silently regenerated. See `15_archive_recovery/LUABI_VISUAL_RECOVERY.md` for the current Lùabi source-image recovery record.

## Ingestion rule

Production experiments, sketches, generated studies, references, and interactive visualizations stay distinct from locked visual canon until they have provenance, creator approval, accessibility description, and explicit registry status.
